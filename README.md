# Coffee Shop Sales Analysis

## Project Overview

This project analyzes coffee shop transaction data using Microsoft Excel. The objective is to explore sales performance, identify transaction patterns, and present business insights through an interactive dashboard.

## Tools & Techniques

Microsoft Excel

Data cleaning and preparation

Calculated fields and formulas

Pivot Tables and Pivot Charts

Slicers and interactive filtering

Data visualization and business insights

## Dataset

Data is taken from Maven Analytics 

The workbook contains transaction-level data with fields such as:

Transaction ID, date, and time

Transaction quantity and unit price

Store ID and store location

Product category, type, and product detail

Revenue

Month, weekday, and hour

## Analysis Performed

Analyzed monthly revenue trends.

Compared transaction counts across weekdays.

Examined transaction activity by hour.

Compared transaction counts across product categories.

Summarized product-level transaction counts and revenue.

Explored differences between store locations using a slicer.

## Dashboard Features

Four charts covering monthly, daily, hourly, and category-level trends

Interactive store-location slicer

Product sales summary

Key business insights

Coffee-inspired dashboard design

## Key Findings

Friday recorded 21,701 transactions in the saved weekday summary.

June recorded the highest monthly revenue in the saved monthly summary: 166,485.88 currency units.

The dashboard enables further exploration of product performance and transaction patterns by store location.

## Files

Excel workbook containing the transaction data, Pivot Tables, charts, and dashboard.

How to Explore

Download the Excel workbook present in repositery.

Open it in desktop Microsoft Excel.

Navigate to the Dashboard sheet.

Use the store-location slicer to explore the available views.

Review the Pivot Tables for supporting summaries.
